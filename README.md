# P-Gelados
Jogo 3D de Pinguim

Um pinguim precisa recolher peixes para alimentar sua família enquanto atravessa uma região congelada.

Coleta: peixes.

Inimigos: focas hostis ou outros animais fictícios.

Dano: contato com inimigos e obstáculos.

Pontuação: peixes coletados.

Vitória: reunir a quantidade necessária e chegar ao iglu.

Derrota: perder todas as vidas.

Visual: neve, blocos de gelo e rampas. O personagem pode ser substituído por uma esfera caso vocês não tenham um modelo 3D.
